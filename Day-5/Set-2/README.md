# Set 2 – Bank Branch Accounts and Customer Activity

## Overview
This assignment focuses on managing bank branch accounts and customer activity using SQL Server and MongoDB.

## Technologies Used
- SQL Server
- MongoDB
- MongoDB Compass
- SQL Server Management Studio (SSMS)

## Files Included

| File Name | Description |
|---|---|
| `schema.sql` | Database creation, table creation, primary keys, foreign keys and constraints. |
| `seed_data.sql` | Sample data insertion, UPDATE, DELETE, SELECT queries and DROP, TRUNCATE and DELETE testing. |
| `MongoDB_Queries.docx` | MongoDB database creation, capped collection, insertion of 20 activity documents and retrieval of the last five login events. |

## Tasks Completed
1. Database normalisation and identification of candidate and composite keys.
2. Creation of tables with IDENTITY keys and constraints.
3. Practical comparison of DROP, TRUNCATE and DELETE.
4. INSERT, UPDATE, DELETE and SELECT operations using WHERE conditions.
5. MongoDB capped collection creation and customer activity log management.

## Note
SQL queries are maintained in SQL files, and MongoDB queries with execution outputs are documented in the Word document.
