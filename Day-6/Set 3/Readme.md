# SET 3 – TELECOM USAGE AND BILLING REPORTING

## Overview
This task focuses on generating telecom usage and billing reports using SQL Server and MongoDB.

## Technologies Used
- SQL Server
- MongoDB
- MongoDB Aggregation Pipeline

## Files Included

1. **reports.sql**
   - Database and table creation
   - Sample data insertion
   - Eight SQL reporting queries
   - String and date functions
   - NULL handling using SUM() and AVG()

2. **output.docx**
   - SQL query purposes and expected outputs
   - String and date function explanations
   - NULL handling demonstration
   - Three MongoDB aggregation pipelines
   - MongoDB expected outputs
   - Conclusion

## SQL Reports Covered
1. Total call minutes per plan
2. Subscribers exceeding their data limit
3. Month-wise revenue
4. Invoices overdue by more than 15 days
5. Subscribers with no usage
6. Average Revenue Per User (ARPU) by circle
7. Plan popularity
8. Top 10 data consumers

## MongoDB Aggregation Pipelines
1. Hourly usage report
2. Average session length
3. Busiest cell tower

## Concepts Covered
- JOIN operations
- GROUP BY and HAVING
- Aggregate functions (SUM, AVG, COUNT)
- LEFT JOIN
- String functions
- Date functions
- NULL handling
- MongoDB aggregation operators

## Conclusion
Successfully implemented telecom usage and billing reports using SQL Server and MongoDB to analyze subscriber activity, data consumption, revenue and network usage.
